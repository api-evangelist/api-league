# API League

> API League is a hub of 55 read-only HTTP APIs across twelve categories — Books, News, Humor,
> Food, Knowledge, Games, Art, Web, Text, Media, Math and Storage — behind one host, one API
> key and one OpenAPI 3.0 contract. Operated by skycraft GmbH (Dresden, Germany), which has
> been shipping developer APIs since 2015. Every operation is an HTTP GET; there are no
> webhooks, no events and no OAuth.

Generated by API Evangelist from the provider's public surface on 2026-09-02. API League does
not publish an llms.txt of its own: https://apileague.com/llms.txt returns HTTP 200 serving the
site's catch-all homepage HTML, not a text document.

## How to call it

- Base URL: https://api.apileague.com (no version segment)
- Auth: an API key, either as `?api-key=YOUR-API-KEY` or as the `x-api-key` header. Prefer the
  header — the query form puts the secret in logs, history and referrers.
- Get a key: https://apileague.com/console/ (free plan, no card)
- Errors: flat JSON `{"status","code","message"}`. 401 no/bad key · 402 daily token quota gone ·
  403 not permitted · 404 unknown id · 406 bad parameters · 429 rate or concurrency exceeded.
  Not RFC 9457.
- Budget: read `X-API-Quota-Request`, `X-API-Quota-Used` and `X-API-Quota-Left` off every
  response. Billing is per TOKEN, not per request, and a token cost varies by endpoint and by
  parameters. Quotas reset at midnight UTC.
- Throttling: there is NO `Retry-After` and no `RateLimit-*` header. On a 429 you must use your
  own backoff. Concurrency is a separate ceiling from request rate.
- Pagination: `number` + `offset` in, `total_results`/`available` + `number` + `offset` back.
- Caching: the terms of use forbid storing API League data; with written permission a cache may
  be held for at most one hour. Do not build a durable index on this API.

## What does not exist

Recorded so an agent stops looking: no MCP server (mcp.apileague.com does not resolve), no A2A
agent card, no `.well-known` document on any host, no webhooks or events, no AsyncAPI, no
GraphQL, no gRPC, no SOAP/WSDL, no CLI, no changelog, no deprecation policy, no OAuth, no
sandbox or test keys, no published security or trust-center page.
